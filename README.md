# Project Timeline Calendar

เว็บสำหรับวางแผนไทม์ไลน์โปรเจ็คแบบ Gantt / roadmap (ไม่มีระบบ login)

- เพิ่ม / แก้ไข / ลบ **โปรเจ็ค** (ชื่อ, สี, วันเริ่ม, SE, BA, PM, สถานะ In Progress, Task)
- เพิ่ม / แก้ไข / ลบ **ไทม์ไลน์** ในแต่ละเฟส: Plan, Develop, Update, Test, Launch
- แสดงธงวันเริ่มโปรเจ็คด้านบน, แถบเดือน, เส้นแบ่งปี, เส้น "วันนี้" และ legend ด้านล่าง
- เลือกช่วงเดือนที่แสดงได้ (เริ่มเดือน / จำนวนเดือน)
- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ และส่งออก / นำเข้าเป็นไฟล์ JSON ได้

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
หรือ deploy เป็น static site (เช่น GitHub Pages) โดยตั้งค่าให้ใช้ไฟล์ใน root ของ branch

คลิกที่ธงโปรเจ็ค, แถบงาน หรือชื่อโปรเจ็คใน legend เพื่อแก้ไข
